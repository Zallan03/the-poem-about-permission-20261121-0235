## How it works

`main.py` (Python 3.13, standard library only, no network) writes one
original poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when the variable is unset). The output is deterministic: byte-identical
on every run.

Run it:

```sh
python3 -P -s main.py
```

## The poem

> I asked, and the room rearranged itself —
> not the walls, but the weight of who could move.
> You took the question from my hands
> like a key I had been holding wrong,
> and the door I could not open
> opened.
